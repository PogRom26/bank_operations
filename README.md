# Набор функционала для обработки информации о банковских операциях клиента банка

### Проект создан для обучения основным функциям и работе с GitHub и программированию на языке Python
### В проекте реализованы следующие функции:
1. [utils.py](src/utils.py) - модуль содержит следующие функции: 
   2. Функция по определению времени суток и возвращения соответствующего приветствия для клиента;
   3. Функция для формирования dataframe из файла [operations.xlsx](data/operations.xlsx)
   4. Функция по фильтрации полученного dataframe по датам
   5. Функция по сообщению о сумме операций и размере кешбэк по каждой карте клиента
   6. Функция по определению топ-5 финансовых операций по их сумме
   7. Функция по получению актуального курса валют, определённых в файле клиента [user_settings.json](user_settings.json)
   8. Функция по получению стоимости акций, определённых в файле клиента [user_settings.json](user_settings.json)
2. [views.py](src/views.py) - модуль, который собирает все функции их [utils.py](src/utils.py) и формирует общую информацию в json
3. [services.py](src/services.py) - модуль, который содержит в себе функцию по поиску в файле [operations.xlsx](data/operations.xlsx) заданного клиентом слова и выводу всех соответствующих банковских операций
3. [reports.py](src/reports.py) - модуль, который содержит в себе функцию, принимающую dataframe с операциями, категорию затрат и опционально дату для подсчета общих затрат по категории расходов за три месяца


## Установка и использование. 
Установка использования происходит обычным клонированием репозитория

## Установка зависимостей.
[requirements.txt](requirements.txt) содержит зависимости проекта. 
Для установки можно использовать следующий код: 
```
pip install -r requirements.txt
```

## Примеры использования. 
Примеры использования отражены в тестовых документах в папке [tests](tests).
Результаты тестирования указаны в [index.html](htmlcov/index.html)
На момент проверки автором общий процент равен 84%
Не проверенный функции касаются [views.py](src/views.py) - как объеддиняющего модуля
